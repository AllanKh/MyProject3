## HOW TO START THE FIRST TIME :)
1. Clone project
2. Go to the project folder
3. Find the MyProject3.uproject file in the project root directory
4. Right-click the .uproject file
5. Select "show more options"
6. Select compile Visual Studio files at the top
7. Launch the project in Unreal Engine
8. If it asks you to rebuild, click yes
9. Profit
